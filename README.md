Telegram-бот с интеграцией LLM и внешних API

Проект разработан для демонстрации навыков программирования и создания интерактивных медиа-приложений. Это асинхронный Telegram-бот, который взаимодействует с нейросетью Google Gemini. Главная цель проекта — показать умение интегрировать языковые модели в реальные цифровые продукты, настраивать их поведение и работать с внешними данными.

Особенности реализации:

- Ролевое моделирование. Нейросети задан строгий системный промпт, формирующий характер и фоновые знания персонажа для органичного ведения диалога.
- Контроль контекста. Бот запоминает историю сообщений. Для оптимизации нагрузки на API используется алгоритм скользящего окна памяти: устаревшие реплики автоматически удаляются, сохраняя при этом общую логику беседы.
- Использование внешних функций (Function Calling). Модель анализирует запрос и умеет обращаться к сторонним сервисам. Например, для получения прогноза погоды скрипт обращается к серверу OpenWeatherMap, парсит JSON-ответ и передает актуальные данные обратно в нейросеть, чтобы она сформировала точный ответ.
- Безопасность и отказоустойчивость. Архитектура проекта скрывает приватные ключи через переменные окружения, а в коде реализована поддержка проксирования сетевого трафика.

Используемый стек:

- Python 3.10 (модуль asyncio)
- Aiogram 3 (фреймворк для Telegram)
- Google Gemini API (генеративное ядро)
- HTTPX (асинхронный HTTP-клиент)

Структура репозитория:

- main.py: основная логика, промпты и сетевые запросы.
- .env.example: шаблон конфигурации, демонстрирующий соблюдение стандартов безопасности.
- requirements.txt: список зависимостей.

Инструкция по запуску:

1. Склонировать репозиторий на локальную машину.
2. Установить зависимости через pip.
3. Создать локальный файл .env на основе предложенного шаблона и заполнить его ключами доступа.
4. Запустить исполняемый файл main.py.
